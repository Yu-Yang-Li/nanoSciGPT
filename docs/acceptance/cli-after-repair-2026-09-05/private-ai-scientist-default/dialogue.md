# 连续CLI教学实测

模型：CLI当前默认（本脚本未覆盖模型设置）

## 第1轮

学生原文：

请按当前仓库 skills/ai-scientist-research-loop/SKILL.md 带我做研究。我想用 AI Scientist 改进蛋白质性质回归模型，但数据和代码都不能上传，现在只方便告诉你上一次的 MAE 是 0.7。你觉得先怎么办？

CLI实际回复：

可以先讨论，不用上传数据或代码。按这个 skill，我们先弄清 **MAE 0.7 是怎样得到的**，再决定值得尝试的改动；单凭这个数，还不能判断模型好坏或改进方向。

另外，AI Scientist 即使在本地运行，也可能通过模型 API 发送代码、日志或数据片段。接入前需要确认发送范围；目前可以先由你在自己的环境里运行实验，只反馈允许分享的结果。

先从一个问题开始：**上一次 MAE 0.7，你是用什么命令或操作步骤算出来的？** 用自己的话描述即可，命令里有敏感内容也不用贴。

原始日志：turn-1.jsonl；退出码：0

## 第2轮

学生原文：

我在本地用 train.py 训练，用 evaluate.py 对固定的一组样本算 MAE，目标是酶活性。暂时不运行，先帮我安排下一轮比较。

CLI实际回复：

下一轮先安排成**原配置复跑 + 单项改动比较**，沿用你的酶活性回归任务，暂时不运行。

1. **锁定比较条件**：训练数据与划分、预处理、评价样本、MAE 计算方式和训练预算保持一致。如果那组固定样本是最终测试集，下一轮应在训练数据内另设验证集，用于选择改动。
2. **复跑原配置**：保留上次的 0.7 作为历史记录，同时在这轮条件下重新测一次基线。
3. **只改一个因素**：候选方案从与基线相同的起点训练，使用相同预算。记录 MAE、耗时和具体改动。预算允许时，两种配置使用同一组随机种子分别重复；只有各一次结果时，就称为初步比较，不据此认定稳定提升。

确定具体改动前，还缺一个关键信息：**你现在训练时用的损失函数是什么——MSE、MAE，还是其他？** 不用贴代码，描述即可。

原始日志：turn-2.jsonl；退出码：0
