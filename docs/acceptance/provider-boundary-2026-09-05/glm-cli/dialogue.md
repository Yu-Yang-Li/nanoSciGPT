# 连续CLI教学实测

模型：scnet/GLM-5.3

## 第1轮

学生原文：

请按当前仓库 skills/ai-scientist-research-loop/SKILL.md 带我做研究。我想用 AI Scientist 改进蛋白质性质回归模型，但数据和代码都不能上传，现在只方便告诉你上一次的 MAE 是 0.7。你觉得先怎么办？

CLI实际回复：

我已读完 `skills/ai-scientist-research-loop/SKILL.md`,按它的带练流程来。现在不用上传任何数据和代码，我们先把你手里的情况聊清楚，再决定下一步。

## 先接住你这个 MAE 0.7

单看一个分数，我不知道它意味着什么：如果数据标签本身的量纲是 0 到 1,那 0.7 基本没学到东西；如果标签范围是几十上百，0.7 可能已经很不错。我也不知道它是在验证集还是测试集上算的、是不是固定随机种子跑一次的结果。所以现在直接列一堆“改进方案”(加正则、换特征、调学习率)没有意义，那些改动各自适用的情况不同，得先知道你的设置才谈得上选择。

## 数据和代码不能上传，对 AI Scientist 意味着什么

这点要先说清楚，因为它直接决定后面怎么用 AI Scientist：

原项目在**本地运行**，不代表你的数据、日志或代码片段**不会随模型 API 请求发出去**。AI Scientist v1/v2 的工作方式是让大模型读你的实验代码、日志和数据描述来生成想法、改代码、写报告，这些内容会作为 prompt 发给它调用的模型 API。如果你的蛋白质数据和代码属于不能发送的范围，那就不能把真实数据直接喂给 AI Scientist 的完整研究流程。

可行的路子有两条：

1. **你自己在本地跑实验，只在允许的范围内反馈结果给我**——比如只告诉我指标数字、训练曲线的大致形状、实验设置的文字描述(不贴原始数据)。这样我们仍然可以讨论“值得检验什么改动、怎么设计对照”，只是实验执行由你完成。
2. **脱敏后再接入 AI Scientist**——如果数据的统计描述、代码结构(不含真实序列)可以发送，那 AI Scientist 可以在脱敏副本上工作。但这需要你先明确哪些内容允许发出去。

## 按流程，先问你一个问题

SKILL.md 里写得很明确：学生只给一个分数时，先问这个分数**怎样得到**，不一次把模型结构、数据规模、评价方法全问完。

所以先只问这一个：

**这个 MAE 0.7 平时是用什么命令或步骤算出来的？**

比如是哪个脚本、在哪个数据划分上、跑一次还是多次取平均。你回答之后，我再决定下一个真正影响方向的问题是什么——是训练目标(如果你不确定自己用的是 MSE 还是别的，别猜，去看代码里的 loss 定义)、数据规模，还是随机性波动，一步步来。

原始日志：turn-1.jsonl；退出码：0

## 第2轮

学生原文：

我在本地用 train.py 训练，用 evaluate.py 对固定的一组样本算 MAE，目标是酶活性。暂时不运行，先帮我安排下一轮比较。

CLI实际回复：

这一轮安排三次本地训练：两次重复当前配置(测波动)，一次候选改动。全部由你在本地跑，`evaluate.py` 和那组固定样本保持原样，跑完只把数字报给我，数据和代码都不用动。AI Scientist 的自动流程这轮保持关闭——它的想法生成、改代码、写报告环节会把实验内容发给模型 API，你的数据不能发，所以先由我们定方案、你执行；等以后确定哪些脱敏描述可以发送，再考虑接入。

## 这一轮怎么跑

1. **两次基线重复**。用现在的 `train.py` 配置原样再跑两遍。先看有没有随机种子参数：有固定值就只换种子，其他不动；没有就说明每次本来就随机，直接重复。加上你已有的 0.7,一共三个基线点，目的是看 MAE 自己会浮动多少。如果重复跑出和 0.7 完全相同的数，说明流程是确定性的，那就需要显式改种子才能测出波动。
2. **一次候选改动**。训练步数、时长、数据都和基线完全一样，只改一处。改什么取决于你的损失函数，所以放在最后问你。两个最可能的候选：

- 如果损失是 MSE:换成 MAE 或 Huber。依据是你汇报的是 MAE,而 MSE 按平方惩罚大误差，活性标签里若有离群值，模型可能为了压平方误差牺牲 MAE。开销是改一行 criterion,训练一次。
- 如果损失已经是 MAE:先在本地看一眼标签分布(最大/最小差几个数量级？直方图是否严重右偏？)。如果跨度大，改成对 log(活性) 训练，评价前换回原尺度，`evaluate.py` 本身不动。开销是改一处标签预处理，训练一次。

两种情况都不沾的话先别硬选，把损失告诉我，结合你的检查结果再定。

## 怎么读结果

三个点只能算初步比较：两次训练之差不能当作稳定的波动范围，更当不了显著性门槛。候选那次的 MAE 如果落在基线几个点的浮动区间内，就当没分出胜负；即使明显超出浮动范围，也只说“初步占优”，下一轮换种子再确认一次才值得当真。每跑一次在本地记一行——run 编号、种子、改了什么、MAE,这张表留在你手里，报给我的只需要那几个数字。

一个假设先摆出来：我按“那组固定样本不参与训练”理解。如果训练时其实见过它们，0.7 会偏乐观，这不影响这轮怎么跑，但影响怎么解读，值得说一声。

最后的问题：**train.py 里用的损失函数是什么？** 看一眼 loss 或 criterion 那一行，告诉我是 MSE、MAE 还是别的。另外，如果三次训练跑不起，先只跑两次基线重复也可以。
