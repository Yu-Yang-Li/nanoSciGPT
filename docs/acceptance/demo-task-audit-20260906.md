## 页面对齐

- P1：baseline；真实数据检查、训练和结果解读。
- P2：仍由baseline接待另一类科学数据或学生数据，核对实际可用目标；有标签则训练，没有标签则不编造监督分数，并自然引出预训练。现有录像清单缺少独立P2实操；本机旧版 `ai4s-course-teaching` 的P2“不推荐模型”描述不能覆盖用户已定稿要求。
- P3：文本预训练及回答微调。标点密度100%结果不用于替代该页需求。
- P4：蛋白质等科学语言训练与下游任务，需先修正基础示例并复验。
- P9—P11：沿用合格的基础模型做迭代与研究；正负结果均保留，不要求每个研究分支涨分。

## 正式截图前必须完成

1. 定义每步要展示的能力与比较对象，不以所有步骤涨分为目标。
2. 蛋白质选择信息范围一致的任务，优先评估带真实实验标签的小型任务；保留nanoGPT从头训练路线，不偷换成调用大型预训练模型。若保留组成任务，明确教学标签，不能把公式可直接计算的性质包装成生物发现。
3. SMILES保留真实标签，检查合理训练预算与简单基线；文本修正无区分能力的评估，并独立检查问答任务。
4. 基础模型在固定开发设置与多随机种子下复验；若要声称预训练有帮助，增加相同数据和下游训练预算的随机初始化对照。锁定设置后使用未参与选择的样本检查，不为涨分反复挑种子或更换验证样本。
5. 保存自然对话、命令、逐样本预测、图表和完整结果；实际完成Qoder教学对话后才能称为助教实测。
6. 截图仅裁切真实对话与产物；页内按点击显示输入、必要反问、运行结果、结果解释。大结果图替换展示，小对话顺序保留，避免多图互相遮挡。没有实施PPT改版。
