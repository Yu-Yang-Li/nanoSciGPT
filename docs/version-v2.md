# V2 定稿：十一个方向的科学问题与技术口径复核（2026-11-27）

V2 在 V1 的十一个方向上做了最后一轮专业复核。十个科学方向加一个语言对照，逐个核对了标签的定义和单位、数据的来源和范围、训练池与两组留出样本是否重样，以及“同一个 nanoGPT，只换编码器和读出头”是否在代码里成立。**结论：十一个方向可以作为教学定版使用。** 下面把每个方向的依据和已知限制写清楚，供授课时对外说明。

## 技术口径

十一个方向共用 `nanoscigpt/scientific/scigpt.py` 里的两层、两头、32 维因果 Transformer。位置嵌入、注意力块和最后的 LayerNorm 直接取自仓库的 nanoGPT 实现；方向之间只换三样东西：把观测切成 token 的编码器、预训练时预测的目标（符号用交叉熵，数值块用均方误差，晶体用元素交叉熵），以及下游的一个线性读出。编码器只有三种：符号序列、数值块、晶胞；十一个方向按输入类型选用。文本的读出额外把模型对每个对象的平均预测损失和最大预测损失作为两个特征，仍接在冻结主干之后。

每个方向用 200、800、3,200、12,800 个无标签对象预训练，五个种子，然后只用 32 个标签训练读出，在两组未参与训练的留出样本上各测一次。十一个方向的下游误差在两组留出上都随预训练数据量逐档下降，预训练损失在十个方向也逐档下降。逐项数字和口径差异见[规模实验总表](pretraining-scale/shared-checkpoints/README.md)。

## 已知限制

这些限制已经写进各方向的说明和规模实验页，授课时可以直接引用。

- **五个模拟方向**（光谱、三维结构、天气场、扩散场、天文图像）是公式生成的理想化数据，结论说明的是方法在这个设定下成立，不能外推到真实观测。每个方向的生成方式和“它不是什么”见[数据来源页](../data/eleven/SOURCES.md#模拟数据指什么)。
- **最容易被专业读者追问的两项是天气场和 RNA。** 天气场实际是两团亮斑的序列，课上按“时空图像序列”讲，别当成气象数据；RNA 的标签是三核苷酸熵，课上按“局部组成统计”讲，别当成 RNA 结构或功能结论。这两句说清楚，其余模拟方向都是教科书式的理想化模型。
- **RNA 的标签简单。** 三核苷酸熵能直接从序列数出来，不预训练的模型也能读出一部分，所以末档只比只猜均值好约 10%。它检验的是模型有没有保留局部组成信息，与 RNA 的结构和功能无关。
- **DNA 的预训练语料和下游不完全对应。** 预训练读酵母基因组窗口，下游是人工设计的短发夹。基因组片段到 3,200 条后预训练损失基本不再下降，下游靠微调还在变好。改用同一实验的两万多条发夹预训练，又因为骨架种类少，800 条就学完了，下游反而不如不预训练。
- **晶体的标签少。** 只有 32 个标签时，不预训练的模型怎么读出都比只猜均值差；200、800 两档也不如只猜均值，到 3,200 档才超过。形成能是计算值，氧的参考态取自水蒸气中的化学势，绝对误差不能和专用材料模型相比。
- **小分子有一组反向。** sp³ 比例在留出组 A 的 12,800 档比不预训练差 7%，B 组好 5%。
- **文本是语言对照，错误是人为加的。** 末档是只猜均值的 0.69 和 0.71 倍，B 组 0.707 没到打磨时事先定的 0.7 门槛。换进主表是在看过结果之后做的决定。
- **绝对误差不能跨领域比较。** 两层、32 维、32 个标签的设定是为了让曲线和代码在 CPU 上可读，不代表各领域的实用精度。

## V2 相对 V1 的改动

- 文本的下游任务从“去掉空格后数词数”改为“数被替换的字母”，读出改为冻结表示加模型自身的预测损失。旧任务保留在 `data/eleven/text.npz` 的 `wordcount` 前缀下，自动研究的存档继续用它。
- 数据来源页按实际数据修正了 DNA 的发夹数量和熔解温度范围、文本的行长范围。
- 首次使用检查在 Windows 和 WSL 上按这份 README 重做，[记录在这里](first-run.md)。

V2 的代码和文档在本地分支 `classroom/one-backbone` 上提交，尚未推送。
