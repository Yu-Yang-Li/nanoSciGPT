# 课堂对话：从光变分类到计算研究

以下是准备试用的学生提问，不是已经发生的对话原文，也不要求每个学生恰好问三句。学生可以追问、换自己的数据，或让助手多解释一下。助教按当前问题接话，不按幻灯片页码自动推进。

## 开始之前

按仓库 README 安装后，在仓库目录打开 Qoder 国内版，选用自己的内置模型。第一次说：

> 请读这个仓库 skills/README.md 里的三个 Skill，接下来带我做实验。

然后自然提问即可。学生带自己的数据时沿用自己的任务；教师贯穿演示使用 StarLightCurves 光变，不是光谱。数据准备与命令见[光变课堂说明](starlight-classroom.md)。

## P1：先做一个分类模型

1. 我想用课程里的光变数据做分类，帮我跑一遍吧。
2. 这个结果怎么看？我之前没学过机器学习。
3. 那能说明模型学到了恒星的物理规律吗？

使用 baseline Skill，当前课堂主模型为监督 LSTM，随机森林保留作补充。截图选择：曲线和任务说明；本轮结果；实际分对、分错的样本。解释指标不再重新训练。后面的 GPT 仍保留自身预训练／不预训练对照，不用换架构后的涨分代替预训练比较。

## P2：大量无标签、少量有标签

1. 我有很多光变，但只有一小部分知道类别，这些数据怎么用？
2. 那些不知道类别的光变，也能帮上忙吗？
3. 那你拿这份数据给我讲讲，哪些用来预训练，哪些用来做分类？

仍由 baseline Skill 解释。截图选择：同一条曲线不显示类别时怎样产生预测任务；分类时标签怎样加入。StarLightCurves 本来都有标签，这里是在说明一种使用方式，不伪造额外无标签数据，也不把之前的全标签成绩说成少标签成绩。

## P3：先看文本模型

1. 先用课程里的 nanoGPT，把预训练和问答微调跑一遍吧。
2. 训练前后，它说的话有什么不一样？给我看看。
3. 如果我换个问法，它还能回答吗？

使用科学语言 Skill。截图选择：真实文本样本；模型微调前后原题输出；未见问法的真实回答。小样例不保证问答泛化，失败原文保留，不能拿参考答案代替输出。

## P4：换成光变

1. 那换成我的光变数据呢？这些数字怎么让模型读进去？
2. 明白了，就用刚才的数据训练试试吧，先预训练，再做分类。
3. 如果直接用有标签的数据训练，不做前面那一步，结果会怎么样？

沿用前文选好的数据。截图选择：32 点组成一段；预测片段与真实值；同设置下预训练后分类与直接分类的结果。第三问先读本轮已保存的对照，不自动重跑，也不只选涨分的一次。

## P9：继续改模型

1. 模型已经跑通了，接下来怎么改？用 autoresearch 带我试试吧。
2. 为什么先改这个地方？你觉得之前的问题出在哪？
3. 那就试试，看看是不是真的比原来好。

使用研究 Skill。截图选择：从记录中发现的问题和拟检验解释；真实代码改动与运行；新旧结果及决定。教学适配接着光变任务，不换成原版文本任务。

## P10：做一个小研究

1. 刚才只是改模型。如果想围绕它做个小研究，用 The AI Scientist v1 能怎么做？
2. 你说的这个问题，之前有人研究过吗？我们可以怎么试？
3. 那就按这个安排做吧，做完写份短稿给我看看。

截图选择：研究问题和查证过的文献；实际实验与图；根据真实图表写出的短稿。前两问先讨论与检索，第三问才执行商定安排。稿件不等于结论已经被外部验证。

## P11：根据结果调整研究路线

1. 如果用 v2 接着做，和刚才会有什么不一样？
2. 这几种做法都可以试吗？你觉得先试哪个？
3. 那先做这个，看看结果，再决定后面怎么做。

截图选择：针对当前问题提出的路线；一次实际结果怎样影响下一步；各分支的进展，区分已做和未做。不是固定两条路线，也不是提前写好的赢家。

## 记录要求

保存学生原文、助教原文、执行命令和实际结果。这里的提问可用于新会话试用；最终接受哪些截图，以对应实际记录为准。截图可以裁切无关界面，不改写终端输出，不把两次独立实验拼成一次连续提升。新会话需告知上次的结果路径，不能让助手猜。
