# 首次使用检查（2026-11-27）

Windows 和 WSL（Ubuntu 24.04）都从空目录检出含最终文本任务的本地提交 `1abbb0c`，分别新建 Python 虚拟环境、禁用 pip 本地缓存，并使用新的 Matplotlib 和 Jupyter 配置目录。两边用同一个本地 Git 副本作为克隆源，后续按 README 的 CPU 安装、Notebook 执行和命令行步骤运行。WSL 检出目录放在 Linux 文件系统。

**两边的 11 个方向都跑通。** 每个方向输出 200、800、3,200 三档预训练留出损失和下游误差，以及不预训练和只猜均值的对照。默认扩散场 Notebook 整本执行成功，AutoResearch 随机搜索和星流回放也各走了一次。
