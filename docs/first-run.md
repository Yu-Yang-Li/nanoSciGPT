# 首次使用检查（2026-11-27）

把 `classroom/one-backbone` 分支（提交 acb0648）克隆到空目录，照 README 的“怎么装、怎么跑”从上到下做一遍：建虚拟环境、装依赖、整本执行 Notebook，再把命令行入口各跑一次。pip 不使用本地缓存，Matplotlib 用全新的缓存目录。Windows 和 WSL（Ubuntu 24.04）各做一次，所有步骤退出码都是 0，执行后的 Notebook 没有报错，两边各生成了 15 张图。Windows 上执行后的 Notebook 存为 [eleven_fields.executed.ipynb](../notebooks/eleven_fields.executed.ipynb)。

两台环境都是同一台 24 核电脑，机器上同时有别的任务在占用 CPU，用时偏保守。

## 安装

| 步骤 | Windows | WSL Linux |
|---|---:|---:|

环境：Windows 为 Python 3.12.10，WSL 为 Python 3.12.3；两边装上的是 torch 2.15.0+cpu、NumPy 2.5.5、scikit-learn 1.9.1、Matplotlib 3.11.2、Jupyter Notebook 7.6.5。torch 从 PyTorch 官方源下载，其余包走本机 pip 配置的镜像。安装时间几乎全花在下载上，随网络变化很大。

`jupyter nbconvert --execute` 整本执行，默认方向扩散场，2 个线程。每一节的用时取自执行后 Notebook 里记录的时间戳。

| 节 | Windows | WSL Linux |
|---|---:|---:|
| 第 0 节：选方向、检查依赖、准备字体 | 11 秒 | 6 秒 |
| 第 1 到 3 节：看数据、切 token、搭模型 | 1 秒 | 2 秒 |
| 第 4 节：预训练三档 | 15 秒 | 11 秒 |
| 第 5、6 节：下游训练和评测 | 4 秒 | 3 秒 |
| 第 7 节：读自动研究的存档 | 0 秒 | 0 秒 |
| 第 7 节：现场随机搜索 2 轮 | 3.3 分钟 | 82 秒 |
| 第 8 节：星流的四组图 | 7 秒 | 3 秒 |
| 合计 | 3.9 分钟 | 1.8 分钟 |

WSL 没有预装中文字体，第 0 节下载了一次 Noto Sans SC，图里的中文正常显示。

## 命令行入口

| 命令 | Windows | WSL Linux |
|---|---:|---:|
| `python -m autoresearch.common_search --field field --method random --rounds 2 --seeds 53` | 4.8 分钟 | 3.0 分钟 |
| 同一条命令去掉 `--seeds 53` | 36.0 分钟 | 23.4 分钟 |
| `python -m autoresearch.replay_stream` | 1 秒 | 1 秒 |

第一条是 README 里的命令，和 Notebook 第 7 节的现场搜索设置相同。它是在安装完成后、把克隆更新到提交 d1d1a2d 再测的，因为 `--seeds` 这个选项正是这次检查之后加的：检查时 README 写的是第二行那条命令，每个配置用 3 个种子打分、结束后再用 5 个种子评留出，在这台有别的任务的机器上要跑二三十分钟，不适合当作快速示例。

`python -m nanoscigpt.tasks.eleven --field <方向>`，种子 53，预训练 200、800、3,200 三档，依次运行：
