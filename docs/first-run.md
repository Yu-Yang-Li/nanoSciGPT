# 首次使用检查（2026-11-27）

把 `classroom/one-backbone` 分支（提交 152e65a）克隆到空目录，照 README 从上到下做一遍：先走“三分钟上手”，再装 Jupyter 整本执行 Notebook，最后把命令行入口各跑一次。每次都在一个全新的虚拟环境里装，pip 不使用本地缓存，Matplotlib 用全新的缓存目录。Windows 和 WSL（Ubuntu 24.04）各做一次，所有步骤退出码都是 0，执行后的 Notebook 没有报错，两边各生成了 17 张图。Windows 上执行后的 Notebook 存为 [eleven_fields.executed.ipynb](../notebooks/eleven_fields.executed.ipynb)。

两个环境在同一台 24 核电脑上，检查时机器上同时有别的任务在占用 CPU，用时偏保守。

## 三分钟上手

| 步骤 | Windows | WSL Linux |
|---|---:|---:|
| 克隆仓库 | 1 秒 | 6 秒 |
| 装 CPU 版 torch | 73 秒 | 1.5 分钟 |
| 装项目（`pip install -e .`） | 57 秒 | 62 秒 |
| `python -m nanoscigpt.quickstart` | 33 秒 | 23 秒 |
| 合计 | 2.7 分钟 | 3.0 分钟 |

最后一条命令自己报的训练用时是 Windows 22 秒、WSL 18 秒，其余是启动和读数据。两边都写出了 `quickstart-field.png`。安装时间几乎全花在下载上，随网络变化很大：前一天同样的安装用了半小时左右。

环境：Windows 为 Python 3.12.10，WSL 为 Python 3.12.3；两边装上的是 torch 2.15.0+cpu、NumPy 2.5.5、scikit-learn 1.9.1、Matplotlib 3.11.2、Jupyter Notebook 7.6.5。torch 从 PyTorch 官方源下载，其余包走本机 pip 配置的镜像。

先装 Jupyter（`pip install -e ".[notebook]"`）：Windows 59 秒，WSL 42 秒。然后 `jupyter nbconvert --execute` 整本执行，默认方向扩散场，2 个线程：Windows 2.7 分钟，WSL 2.3 分钟。每一节的用时取自执行后 Notebook 里记录的时间戳。

|---|---:|---:|

| 第 1 到 3 节：看数据、切 token、搭模型 | 2 秒 | 1 秒 |
| 第 4 节：预训练三档 | 18 秒 | 15 秒 |
| 第 5、6 节：下游训练和评测 | 5 秒 | 4 秒 |
| 第 7 节：读自动研究的存档 | 1 秒 | 0 秒 |
| 第 7 节：现场随机搜索 2 轮 | 2.1 分钟 | 1.7 分钟 |

| 第 8 节：星流的四组图 | 3 秒 | 3 秒 |
| 合计 | 2.6 分钟 | 2.2 分钟 |

WSL 没有预装中文字体，第 0 节下载了一次 Noto Sans SC，图里的中文正常显示。
