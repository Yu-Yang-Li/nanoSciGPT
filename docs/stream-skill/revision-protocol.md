# GD-1 调参经验复验约定

在生成新版经验和查看任何新场景成绩前锁定。

- 起点取已封存的第八轮经验。DSK 一次性读取原八轮全部 16 个训练场景的摘要，每个场景包含真值、每批最佳候选、与上批最佳相比的单参及多参试探结果。仅使用训练文件。帮助智能体区分可迁移的步骤和少数场景适用的绝对数值，生成一份最多 1,500 字的新经验。经验正文计算 SHA-256 后冻结。
- 两套经验使用相同的 DSK 模型、温度 0.5、拟合提示、观测数据和参数范围。每场景四批，每批十组有限参数，共 40 次轨道积分。少交候选的回答重新请求，未评估的无效回答不消耗轨道预算。重复提交的参数仍计入预算。相邻方法交错调度。
- 开发种子 27101–27106。按场景计算新版减旧版的对数差距，即 ln(新版最低 χ² / 旧版最低 χ²)。平均差 ≤ −0.10，且至少 4/6 场景改善，才采纳新版。先把决定写入文件，再启动盲测。
- 盲测种子 27201–27212。无论开发是否采纳，两个锁定版本都评一次，以便报告失败。主对照为新版相对旧版。至少 8/12 场景改善，且配对场景自助抽样 20,000 次（种子 271126）的平均差 95% 百分位区间上界小于零，才算在此盲测上验证了改善。开发没过或盲测没过，不替换旧经验。每种经验在每个场景只运行一次。
- 随机搜索和从边界中心起步的 Nelder–Mead 作为同样 40 次积分的基线。报告四种方法平均 ln(最低 χ² / 真值 χ²)、两两配对结果以及第 10、20、30、40 次评估的最好成绩。不会根据新场景结果再改提示或调门槛。预计 145 次有效 DSK 调用。
