# nanoSciGPT 课程仓库收口规格

## 目标

把已经跑通的六个教学 Skill 整理成学生从 GitHub 克隆后能够安装、运行、复查的正式课程仓库。

## 固定边界

- 保持六个原子 Skill，不增加第七个课程编排 Skill。
- 当前正式课程版本为16页、90分钟；旧版资料进入档案，不与正式导航并列。
- 十类内置数据可直接运行；学生自己的非表格数据需要适配，不宣传“任意数据一键训练”。
- `smoke`只检查环境和代码链路；`classroom`用于课堂展示损失变化和下游任务。
- 课堂模型、评价器、AI Scientist v1/v2均为CPU教学实现，不冒充论文系统完整复现。

## 验收标准

1. GitHub正式树包含16页大纲、逐页文字、讲稿、资料导航和证据包命令。
2. 首页准确列出十类数据、六个 Skill、安装方式、课堂命令和结论边界，不保留旧四域或旧三段式主线。
3. 学生可运行环境检查，再选择一个领域；缺失依赖时得到明确提示。
4. GitHub Actions在Windows与Ubuntu检查安装、Skill格式、smoke路径；完整课堂测试作为独立任务运行。
5. v1不静默覆盖，v2中断后留下可恢复状态；多路线最终使用同一评价器。
6. 领域清单只有一个事实源；新增领域通过明确的数据、表示、任务和评价接口接入。

## 不在本轮扩展的内容

- 不增加新的科学领域或论文案例。
- 不训练论文规模基座模型。
- 不把生成夹具替换成未经核实的大型数据集。
