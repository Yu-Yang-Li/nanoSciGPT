## 第一部分：开场（P1–P4，0–10分钟）

### P1｜Agent能搭模型，但不能替你定义什么算对（0–2分钟）

[开场不寒暄，直接放Agent对话截图]

大家看这个对话。我对Agent说"请你搭建一个GNN，帮我拟合@data/下的分子数据"。三十秒后它给了我什么？完整的代码、训练曲线、测试分数、还有一份分析报告。工程上无可挑剔。

**但我现在问三个问题**：这个数据是谁的、干不干净？这个分数是跟什么比出来的？如果下周数据换了一批，这个结论还成立吗？

这三个问题，Agent一个都不会替你回答。这就是今天这门课的出发点——**Agent时代，写代码不是瓶颈了；知道该建什么、什么时候信它、什么时候停，才是瓶颈。**

[指向双线图]

今天的90分钟走两条线。前半场A线：科学数据怎么变成模型能吃的语言，什么时候值得做基座模型——我们从nanoGPT一路讲到ESM。后半场B线：工具和评价器怎么串成会自我修正的闭环——从最早的机器人化学家讲到今天的AI Scientist。

[停顿，让学生动笔]

现在，请在纸上写下你的研究方向，和一句你真正想回答的科学问题。这句问题今天会用一整节课。

### P2｜你的课题缺的是可复用能力，还是更长的科研过程？（2–4分钟）

写好了？好。现在看这张双轴图。横轴是**能力复用半径**——你的模型是只伺候一个任务，还是能跨任务、跨数据集复用。纵轴是**科研过程长度**——你的研究是一个人手工做完，还是工具能自动执行、反馈能改变下一步。

**这两条轴是独立的。右上角不天然优于左下角。**一个专用模型加人工流程，和一套基座加闭环系统，可能是同样正确的选择——取决于你的课题卡在哪。

[举例]

比如做蛋白结构预测，AlphaFold2已经把单任务做到了接近实验精度——你需要的是调用，不是重建基座。但如果你做的是材料筛选，每天都有新性质要预测，那表征能不能复用就决定了你的产能。

反过来，如果你的瓶颈根本不在模型——数据要三个月才出一批——那再多算力也救不了你，你需要的是B线：让反馈回流的速度快起来。

### P3｜先定义什么算对，再让Agent去做（4–7分钟）

现在讲今天最重要的一个概念：**评价器**。

[放证据阶梯图]

看这个阶梯：模型输出 → 已运行 → 已评测 → 已外部验证 → 科学结论。注意每一级的升级都需要**独立**证据。

我见过太多这样的场景：模型输出一个置信度0.92的候选，直接写进结论。但0.92是模型自己说的——**同一个模型既当运动员又当裁判，这叫自我确认，不叫验证。**

[举具体例子]

假设你做分子性质预测。最低可接受的评价器是什么？不是"模型给的分高"，而是"在留出集上，我的预测误差低于领域公认基线"。再往上，如果这个结果能被独立团队的实验或新观测复核，才到"外部验证"。大多数课堂作业到"已评测"就该停了——**这一级以上每一步，都要外部世界配合。**

**请写下两行字**：第一行，你的课题最低可接受的评价器是什么；第二行，你绝不允许自己越过的结论边界是什么。

这两行字，比今天任何模型都重要。

## 第二部分：A线——领域基座模型（P5–P12，10–38分钟）

### P5｜A前史：专用模型证明任务可学习（10–14分钟）

[切到历史时间线]

A线正式开始。先看前史。

2021年之前的科学模型长什么样？三个代表：AlphaFold2做蛋白结构预测、Pangu-Weather和GraphCast做天气预报。它们的共同点——**单一任务、端到端监督训练、专用架构。**

这一代模型的贡献不是"可复用"，而是证明了**"科学任务可学习"**。在AF2之前，没人确定蛋白折叠这个五十年难题能用端到端深度学习解决。CASP14上AF2达到接近实验精度，这件事改变了整个领域的心理预期。

**但专用模型有一个与生俱来的问题：每个新任务都要从零开始。**新的性质要预测？重新收集数据、重新设计特征、重新训练。Pangu只做预报，AF2不做生成。当任务数量爆炸时，这条路在经济上不可持续。

这就引出了下一页的问题：能不能让模型从数据本身学起，而不是每个任务都等标签？

**记住这一页的定位：专用模型不是落后，它是默认起点。**课程结束时你会发现，大多数课题的正确答案仍然是专用模型——这不是保守，是证据驱动的判断。

### P6｜A1a：文本预训练——nanoGPT跑通"下一个字符预测"（14–18分钟）

[切到终端，开始现场实操]

现在大家亲眼看看预训练在做什么。

[敲命令]

```bash
python -m nanoscigpt.domains.text.prepare
python -m nanoscigpt.core.trainer --domain text --max_iters 100
```

这一MB莎士比亚，65个字符的词表。训练目标只有一个：**预测下一个字符。**注意——没有任何标签，没有任何任务定义，学习信号完全来自数据本身。

[等训练跑完，指loss曲线]

看，loss从4.2降到2.66。模型在学什么？它学到的是英文字符的统计结构——哪些字母常连在一起、单词怎么结尾、句子怎么断。

[运行采样]

现在采样看看：

```bash
python -m nanoscigpt.core.sampler --domain text
```

[念采样输出]

像莎士比亚吗？像。是莎士比亚吗？不是。**没有意义，但有结构。**这就是预训练学到的——统计规律，不是语义。

**这里埋一个伏笔：loss下降不等于学到有用表征。**有没有用，要等下游任务检验。这是第9页的事，记住这个悬念。

### P7｜A1b：科学对象语言化——换tokenizer就换领域（18–22分钟）

[不切屏，直接继续敲命令]

现在做这门课最关键的一步。

```bash
python -m nanoscigpt.domains.protein.prepare --size 500
python -m nanoscigpt.core.trainer --domain protein --max_iters 100
```

[等跑完]

刚发生什么了？**trainer.py一行都没改。**模型架构、训练循环、采样逻辑——全部原样。变的只有两个文件：tokenizer和data prepare。

词表从65个字符变成22个氨基酸字母。数据从莎士比亚变成500条UniProt序列。就这样，**文本模型变成了蛋白模型。**

DNA同理——4个碱基。SMILES同理——33个化学符号。这就是"科学对象语言化"：**氨基酸序列、DNA碱基、分子式，本质上都是离散符号序列，和文本同构。**

[指代码]

看domains/protein/prepare.py——这60行就是"领域插件"的全部。当年ESM、ProtTrans做的就是这件事的放大版：换成65亿条序列，就是ESM-2。

**但要诚实地讲停止边界：500条UniProt不会学到蛋白质生物学。**这一级证明的是"机制可迁移"——同一套代码能跑蛋白；不证明"能力可迁移"——学到的表征真的有生物学意义。后者需要下一页的检验。

### P8｜A2a：换预训练目标——CLM vs MLM（22–25分钟）

[继续终端]

```bash
python -m nanoscigpt.tasks.objective_contrast
```

[指输出]

CLM loss 2.97降到2.76。MLM 3.01降到2.81。两个都在降——目标都能学。

但看架构——**完全相同。差异只有两处：attention mask和loss算在哪里。**CLM是单向的，每个位置只能看左边，预测下一个token。MLM是双向的，随机挖空15%的token，用两边上下文恢复。

**这不是谁更好的问题，是下游用法不同。**要生成——写文章、设计序列——选CLM，因为生成本来就是从左到右。要表征——做分类、做结构预测——选MLM，因为理解一个残基需要看它的双向上下文。

ESM选了MLM，所以它能做结构预测。GPT选了CLM，所以它能写文章。**同一个架构，目标决定用途。**

停止边界：300 iter的小模型显不出真实差距。这一级展示"目标可以切换"，不是"哪个更优"。

### P9｜A2b：表征迁移——预训练到底带来了什么（25–29分钟）

[语气转认真，这是全课最重要一页]

现在做这门课最重要的实验。

```bash
python -m nanoscigpt.tasks.transfer_probe
```

[等输出，慢慢念]

one-hot编码：100%。随机初始化的编码器：98.3%。**我们刚预训练的编码器：95%。**

[停三秒，让学生消化]

**迁移增益是负的。**我们花时间预训练的模型，在下游任务上不如直接用one-hot。

这不是实验失败。**这是本课程要证明的核心事实：数据规模不够时，"预训练"这个词只是自我安慰。**

ESM-2用了2.5亿条序列。我们用了450条。差六个数量级。同样的方法、同样的架构——**机制相同、规模决定成败。**这就是从nanoGPT到科学基座的分界线，不在线上，在数据量上。

**所以"基座"的主张怎么证？看迁移合同**：两个共享任务、冻结探针对照从头训练、标签预算阶梯、逐任务报告、OOD留出。每一项都要过。我们的450条，第一项就倒。

[指ESM对照]

作为对照，ESM-2 8M——一个很小的真实基座——一行代码加载，就能提取残基级表征。同样的思想，在2.5亿序列上，迁移合同成立。

**记住这个负结果。第11页做路线决策时，"迁移证据"这一栏你们要诚实地填"否"。**

### P10｜A3a：多任务统一——基座的最小结构隐喻（29–32分钟）

[回到轻松节奏]

如果迁移合同成立了，下一步是什么？多任务统一。

```bash
python -m nanoscigpt.tasks.multihead
```

输出：共享编码器，分类准确率100%，回归MAE 0.27。

**这是基座的最小结构隐喻：一个共享编码器加N个轻量任务头。**任务行为差异来自头部，表征复用来自编码器。ESM3、Aurora就是这个结构的放大——编码器统一了，头按任务挂。

**但这页有个更有价值的失败案例。**最初版本我们用parity任务做分类——前三个token之和的奇偶性。共享编码器只能到45%。为什么？均值池化把顺序信息丢了，而parity对顺序敏感。

**这不是bug，是"表示瓶颈"的活教材**：多任务学不动时，先问池化方式丢没丢任务需要的信息，再问模型够不够大。

停止边界：合成双任务验证的是结构可行性，不是真实科学任务的增益。

### P11｜A3b：路线决策——五问决定要不要基座（32–35分钟）

```bash
python -m nanoscigpt.tasks.route_decision
```

[指输出]

看这个判断：数据不足，降级为专用模型。

**五问决策链**：一，无标签数据是否万级以上？二，是否有两个共享结构的任务？三，迁移是否优于从头训练？四，算力和维护责任是否就位？五，OOD下是否稳定？

**任何一问失败，都有降级路径。**数据不够回专用模型；任务只有一个回专用模型；迁移没证据回专用模型。

四条路线是**平行的选择**：继续专用、调用现成、适配基座、训练新基座。新训练不是最高级，是最后选项——只有前三条都不够、且长期多任务复用可验证时才解锁。

**你的课题大概率停在专用模型。这是合格结论，不是失败。**用一张纸对五问逐条回答，得出你自己的路线判断——这就是A线的作业。

### P12｜A线收束+过渡：你的V0→T4就是科学模型史的缩影（35–38分钟）

[切到对照表]

A线结束前，看这张表。

你刚跑的nanoGPT文本版——对应GPT家族，差在数据量：万亿token vs 一兆。你换tokenizer跑的蛋白版——对应ESM，差在序列数：2.5亿 vs 450。你的transfer_probe——对应ClimaX和scGPT的迁移合同，同一方法、差六个数量级。

**你今天走的路，就是2018到2026年科学基座模型的真实历史。**专用模型→对象语言化→换目标→迁移检验→多任务统一→路线决策。每一步你都亲手做了一遍最小版本。

**区别只有一个字：规模。**方法你已经会了；剩下的是数据、算力和维护——那些不是技术问题，是工程和资源问题。

但A线只回答了一半问题。你的模型训好了——然后呢？**科研不是一次训练，是一个循环**：提出假设、跑实验、看结果、修正假设、再跑。模型只是循环里的一个工具。

下一半场讲：怎么把工具串成会自我修正的闭环。这就是AI Scientist。

## 第三部分：B线——AI Scientist（P13–P19，38–70分钟）

### P13｜B前史→S1：从窄目标自动化到假设生成（38–42分钟）

[切到B线时间线]

后半场开始。先讲历史。

自主科研不是2023年才有的想法。2015年的Adam、2019年的Eve、2020年的移动机器人化学家——这些系统早就证明了**窄目标自动化可行**：给定一个明确的优化目标，机器能自己设计实验、执行、根据结果调整。

**但它们都有一个共同限制：目标是人预设的。**Adam优化酵母杂交，Eve优化药物筛选——机器不参与"研究什么"这个决策。

[指向S1阶段]

2023年之后，变化来了。AstroInsight代表的新范式：**系统开始参与生成假设本身。**

它的流程分四段：从数据统计生成想法——注意，输入是数据统计，不是空想；然后结构化评分——新颖度加可行性减模糊度；然后专家验证——人类专家打分，低分想法淘汰；最后进入假设库。

**核心区别在这：LLM生成的想法不是假设。经过评分、重写、专家验证的，才算。**

[现场实操]

```bash
python -m autoresearch.hypothesis --domain protein --auto_approve
```

[指输出]

看这三个想法。注意IDEA-C——它预测"这个数据规模做不出基座模型"。**负向假设比正向假设更接近真实科研。**真正的研究里，知道什么行不通和知道什么行得通同样有价值。

停止边界：S1的产物是"经过验证的假设"，不是"科学发现"。想法被接受不等于被支持——支持要靠实验证据，那是下一页。

### P14｜S2：实验闭环——反馈改变下一步（42–47分钟）

[语气加重，这是B线核心页]

假设有了，怎么跑实验？这一页讲B线最核心的判定标准。

```bash
python -m autoresearch.experiment --domain protein --auto_approve
```

[指输出，逐个讲]

看三个东西。

第一，**计划是数据结构**。plan: prepare, train_v0, train_extended, sample——每个步骤都有reason，不是自由文本。这意味着计划可以被检查、被修改、被拒绝。

第二，**人工门真实存在**。train_extended需要批准。我可以拒绝它——实验就停在合同边界。这是设计，不是故障。

第三，**失败被保留**。看这行：gain +0.0000，fail。200次迭代不比100次更好。这个"失败"没有被删除，被记录下来了——**收益饱和本身就是发现。**

[切到判定标准]

现在给出闭环的定义：**闭环的判定标准不是"跑了多少步"，而是"反馈是否改变了下一步"。**

如果系统连续三轮用同样的参数，不管结果好坏——那是流水线，不是闭环。如果第一轮结果不好，第二轮换了策略，第三轮根据第二轮又调整了——这才是闭环。

**反馈身份也要分四级**：真实实验或观测——物理反馈，最高级。模拟或形式化验证——计算反馈，可信但有限。历史数据回放——REPLAY，只是重演不是新证据。模型自评——自我确认风险，不能单独支撑结论。

停止边界：S2证明"循环可执行且反馈改变行动"，但不能证明"科学增量"——教学数据永远到不了外部验证。

### P15｜人的责任移动到关键决策（47–51分钟）

[实操演示]

```bash
python -m autoresearch.run --domain text --fresh
```

[不加--auto_approve，让门真实等待]

看，程序停下来了。它在等什么？等批准。预算要增加，这是高成本动作，必须人签字。

**这就是scientist-in-the-loop的本义：不是处处点确认，而是关键节点必须有人的授权。**

权限分四级：自动执行；自动执行并通知；执行前需要批准；仅人工。怎么分配？看两个指标——**可逆性和失败成本。**可逆的、失败代价小的，自动化。不可逆的、失败代价大的——比如删除数据、控制设备、发布结论——必须人工。

**全部人工，自动化价值归零；全部自动，风险不可接受。**好的设计是把人工用在刀刃上。

停止边界：有人参与不自动证明可信。人工确认不替代评价器和原始证据——人也会错，关键是证据链完整。

### P16｜B线交付：闭环设计卡（51–55分钟）

[收拢节奏]

B线讲完三段，现在判断你的系统到底到哪一层。

**四级层级**：L1可执行步骤——一个动作能跑、能判定。L2可追溯工具工作流——工具有合同、有输入输出、有日志。L3目标明确的反馈闭环——反馈真实改变下一步。L4跨轮研究状态——假设、证据、失败跨轮保存。

**判定规则是自动降级**：无评价器不到L1；工具不可追溯不到L2；反馈不改变下一步不到L3；失败和版本不跨轮不到L4。

```bash
python -m autoresearch.run --domain text
```

[指输出]

看——不加--fresh，直接恢复到上次的终态。**研究状态是跨轮持久的。**这就是L4的样子：假设版本、支持证据、反证、失败，全部在research_state.json里。

**"暂不构成闭环"是合格结果。**停在L2工具工作流不丢人——大多数真实系统就停在这。虚报层级才丢人。

### P17｜两轨汇流：模型成为工具（55–58分钟）

[切到汇流图]

现在把两半场接起来。

A线产出的是什么？一个训好的模型。B线需要的是什么？可调用的工具。**汇流点就在这：模型成为闭环里被调用的工具。**

[指正确链]

完整链条：问题 → 数据对象 → 模型工具 → Agent行动 → 独立评价器 → 反馈 → 状态更新 → 人工关口 → 下一行动。

**三种典型断链**，大家检查自己的设计：

第一种，模型输出直连结论。模型说这个分子活性高，就直接写"发现高活性分子"——**中间的评价器呢？实验验证呢？**

第二种，同一个模型既生成又评价。模型生成候选，同一个模型打分——自我确认，刚才讲过。

第三种，反馈只写进报告不改行动。分析结果说这个方向不行，下一轮还在跑同样的实验——**那是装饰性反馈，不是真反馈。**

**记住汇流固定句：基座模型提供可复用能力，Agent组织工具和行动，评价器与真实反馈决定证据升级，研究者承担设题、授权、复核和签署责任。**四者缺一不可。

### P18｜教师实演：autoresearch完整pipeline（58–62分钟）

