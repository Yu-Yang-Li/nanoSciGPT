# 课堂对话：从十一方向 Notebook 到自动研究

以下是准备试用的学生提问，不是已经发生的对话原文，也不要求每个学生恰好问三句。学生可以追问、换方向、换自己的数据，助教按当前问题接话。默认方向是扩散场（`field`），换成别的方向只改 Notebook 第 0 节的 `FIELD`，或命令行的 `--field`。

## 开始之前

按仓库 [README](../README.md) 装好依赖，在仓库目录打开编程助手，第一次说：

> 请读这个仓库 skills/README.md 里的三个 Skill，接下来带我做实验。

然后自然提问。命令行等价入口是 `python -m nanoscigpt.tasks.eleven --field field`。

## P1：先得到第一个结果

1. 我想先用扩散场试试，帮我跑一遍吧。
2. 这些数字怎么看？我之前没学过机器学习。
3. “只猜平均值”和“不预训练”这两行是拿来干什么的？

使用 baseline Skill。截图选择：命令行输出，或 Notebook 第 5 节的输出和第 6 节的预测图；只猜平均值、不预训练、预训练三类结果放在一起。MAE 是平均绝对误差，扩散场的单位是扩散系数的 log10。

## P2：大量无标签、少量有标签

1. 我有很多观测，但只有很少一部分有标签，这些数据怎么用？
2. 这个 Notebook 里哪些数据用来预训练，哪些用来训练下游，哪些用来检验？
3. 预训练的时候，模型的“答案”从哪来？

仍由 baseline Skill 解释。课程设置是：12,800 个无标签对象只用来预测下一个 token；每个种子 32 个带标签对象用来训练读出；留出组 A 不参与任何训练，只用来算误差。

## P3：观测怎样变成 token

1. 一条扩散场数据被切成了什么？给我看看第一个 token。
2. 换成蛋白质或者晶体，一个 token 又是什么？
3. 为什么十一种数据能用同一个模型？

使用科学语言 Skill。截图选择：Notebook 第 1 节的样本图和第 2 节的 token 图；README 里的十一方向表。主干是同一个两层的 nanoGPT，换的只是编码器和读出头，第 3 节的参数图能直接看到这一点。

## P4：预训练，再做下游

1. 那就预训练试试，用 200、800、3,200 个无标签对象各来一次。
2. 预训练的数据越多，下游误差有没有变小？
3. 只看一个种子靠得住吗？

截图选择：第 4 节的训练曲线；第 6 节的规模曲线。单个种子会有起伏，结论看 [五种子结果](pretraining-scale/shared-checkpoints/README.md)。

## P9：让 autoresearch 继续改

1. 模型跑通了，接下来怎么改？用 autoresearch 带我试试吧。
2. 它每一轮为什么选这个改法？
3. 跑了八轮，比随机乱试好吗？换一个方向还是这样吗？

使用研究 Skill。截图选择：Notebook 第 7 节某个方向的搜索图和十一方向总图。课堂实验见[十一方向的自动研究结果](autoresearch-eleven.md)：主干固定，只许改 token 的合并、预训练目标与遮盖、训练设置和读出方式；每轮只看开发集，留出组最后评一次。哪些方向跑赢了随机搜索、哪些没有，照结果页讲。扩散场上更早、更细的两版实验见[扩散场的自动研究](autoresearch-field.md)。

## P9b：把经验留下来

1. 每次搜索都从头来，上一次学到的能留给下一次吗？
2. 它的经验是怎么一轮一轮改的？
3. 经验越攒越多，成绩就一直变好吗？

使用研究 Skill。截图选择：Notebook 第 8 节的四组图（轨道叠在观测点上、一次拟合之内、经验怎么改写、盲测成绩）。照[星流拟合的结果](stream-skill.md)讲：带着经验比空经验好，最好的是第 5 轮，之后回升，和同预算的 Nelder–Mead 相比优势不明显。

## P10：做一个小研究

1. 如果想围绕它做个小研究，用 The AI Scientist v1 能怎么做？
2. 你说的这个问题，之前有人研究过吗？我们可以怎么试？
3. 那就按这个安排做吧，做完写份短稿给我看看。

前两问先讨论与检索，第三问才执行商定的安排。稿件不等于结论已被外部验证。
