# 三个方向的固定预算预训练与下游迁移

先登记，后取训练池和开发片段。主问题是固定 1,600 次 AdamW 更新、每批 64 个对象时，扩大无标签池能否在两个留出组上改善下一 token 交叉熵。四个嵌套池为 200、800、3,200、12,800 个对象。记录每个种子实际看到的不同对象数和非填充预测目标数；变长 SMILES 的有效 token 预算可能不同。确认集使用微调前的权重。两组都逐档下降与两组端点均改善分开报告。与既有等步数开发回执逐项核对。

下游另沿用固定平均遍数的四档、32 个标签、原五个种子，以及统一的两层两头 32 维主干、均值池化和线性头。每个方向两个候选，共六个。先在 256 条训练池中每种子固定取 32 条，开发集 480 条。12,800 对 0 预训练的冻结岭回归探针 MAE 至少下降 10%，且至少 4 个种子改善，才跑四档端到端开发微调。开发均值三段均严格下降才可选定。同方向多项符合时取端点相对降幅较大者，平局按下列顺序。选定后生成两组各 480 条留出样本，分别评分一次。两组五种子平均 MAE 都须三段下降才更新十一方向计数。未选中的标签不计算留出成绩。所有方向的无标签留出损失均评估。

- DNA：真实酿酒酵母 64 nt 窗口。标签一是所有重叠三核苷酸的经验 Shannon 熵（bit）。标签二是最长同碱基连续段长度。衡量局部复杂度，均可由序列精确计算。
- RNA：Rfam 15.1 两个核糖体 RNA 家族的真实 32 nt 窗口。标签一为三核苷酸熵，标签二为沿片段相邻碱基的共识配对/未配对状态切换次数，来自 Stockholm SS_cons 字段。注释没有提供给模型。
- 小分子：QM9 SMILES。标签一为位于环中的重原子占全部重原子的比例，标签二为分子图的直径（重原子间最大最短拓扑距离，单位为键）。使用 RDKit 2025.09.6 离线计算参考值。模型输入仅为现有词表的 SMILES token。
- 分区按染色体、Rfam accession、非氢元素组成隔离，排除先前实验曾抽取的相同对象，核酸也排除完全反向互补的重复。沿用已建立的来源分区，因此新的留出对象属于相同来源分区，不声称整张数据集从未接触过。对照组独立于本轮开发，所有抽样依赖对象哈希，和目标值无关。
- 新增任务均为序列统计、已知注释或分子图的计算量。它们用于检验现有表示能否读出结构信息。真实测量性质的实验另保留。
