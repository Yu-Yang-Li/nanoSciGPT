# 换预训练语料：DNA 与 RNA（运行前写定，2026-11-27）

上一轮“四处偏弱方向的打磨”只换了下游任务、读出头和预训练预算。DNA 和 RNA 的问题更像出在预训练语料上：

- DNA 的预训练语料是酿酒酵母基因组的 64 nt 窗口，下游却是 14 到 18 nt、人工设计的发夹。两者长度、成分和结构都差得远，预训练损失在 3,200 → 12,800 档持平，说明再多基因组窗口也学不到更多。
- RNA 的预训练语料只有两个高度保守的核糖体 RNA 家族，32 nt 片段，模型学到的主要是局部组成，下游只好选能直接数出来的三核苷酸熵。

这一轮主干（两层 nanoGPT，N_EMBD=32）、符号编码器、四档规模、每档固定 1,600 次更新、五个种子、32 个标签的抽法都和 V1 相同，只换预训练语料；RNA 同时换下游任务。晶体和文本不在这一轮。晶体的弱点出在 32 个标签下的读出，200、800 档的对象数不变，换语料改不了；文本已经有接近通过的新任务。

## DNA：同一台仪器测过的发夹序列作预训练语料

- 来源：Ke 等 Array Melt 文库全表（GreenleafLab/nnn_paper，arr_v1_n=27732.csv，CC BY 4.0），只取 RefSeq 序列，转成大写。预训练不读任何测量列。
- 预训练语料：Series 不是 WatsonCrick 的全部发夹（错配、凸起、四碱基环、三碱基环等）。去重，去掉与下游面板任一序列相同或互为反向互补的序列。打乱后取 12,800 条作无标签池，另取两组各 480 条作预训练留出。
- 下游：V1 的发夹熔解温度，训练池、留出组 A、B 与 V1 完全相同。开发集改为 Watson–Crick 系列中两态熔解、不在 V1 面板里的发夹，取 480 条（不足就全取），与 V1 面板同一实验来源。
- 编码：1 个碱基 1 个 token，词表与 V1 相同，位置数仍为 64。

## RNA：Rfam 全部家族作预训练语料

- 来源：Rfam 15.1 种子比对（CC0），全部家族。每条种子序列去掉空位，T 换成 U，只保留 ACGU。从第 0 位起切成不重叠的 64 nt 窗口。
- 按家族分组：家族编号的 SHA-256 取模 100，0–79 进无标签池，80–84 训练池，85–89 开发集，90–94 留出组 A，95–99 留出组 B。下游的家族在预训练里都没出现过。每组内去重，并去掉在前面各组出现过的序列。无标签池打乱后取 12,800 条，再从剩余里取两组各 480 条作预训练留出；训练池取 256 条，开发集、A、B 各取 480 条。
- 下游候选（都由序列决定，不能直接从碱基计数得到）：
  - 折叠自由能：ViennaRNA（RNA.fold，37 °C，默认参数）算出的最小自由能除以长度，单位 kcal/mol/nt。数值越低，这段 RNA 自己折叠起来越稳定。
  - 配对位置比例：窗口所在列在该家族共识二级结构（SS_cons）里标为配对的比例。
- 位置数 64。

## 读出与判据

三种读出：probe（冻结主干，岭回归 alpha=1）、probe-cv（留一交叉验证选正则，候选 10^-2 到 10^4 的 13 个值）、ft（全参数微调 200 步，学习率 0.001）。

判据（开发集和留出组相同）：

1. 下游五种子平均误差在 200 → 800 → 3,200 → 12,800 三段都下降。
2. 12,800 档相对 200 档至少 4/5 个种子改善。
3. 12,800 档平均误差不超过只猜均值的 0.7 倍。
4. 12,800 档平均误差低于不预训练。
5. 预训练留出损失五种子平均三段都下降（开发阶段用第一组预训练留出，确认阶段两组都要）。

选择：只在开发集上选。满足判据的组合中，读出优先 probe，其次 probe-cv，再次 ft；同一读出取 12,800 相对 200 端点降幅最大者。选中的组合在留出组 A、B 上各评一次，两组都满足才算通过。

## 补充：事后检查（开发结果出来后写定）

开发集上 DNA、RNA 都没有满足判据的组合。RNA 折叠自由能的冻结读出（probe）满足 1、2、4、5 四条，只差第 3 条（0.84 倍）。第 3 条“末档不超过只猜均值的 0.7 倍”是上一轮打磨时加的，V1 主表入表时没有这一条。因此把这个组合在留出组 A、B 上各评一次，结果按两套标准分别报告：本约定的五条判据，以及去掉第 3 条后的 V1 入表标准。这一步是看过开发结果之后决定的，不算按约定通过。
