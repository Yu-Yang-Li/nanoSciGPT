# 四项偏弱方向的打磨：实验约定（开发集结果出来前写定，2026-11-27）

V1 主表里有四处偏弱：晶体形成能在 200、800 档不如只猜均值；文本词数和只猜均值差不多；RNA 三核苷酸熵只比只猜均值好约一成，而且标签能从输入直接数出来；DNA 的预训练损失在 3,200 → 12,800 档持平。这一轮每个方向试一组事先列定的改法。主干（两层 nanoGPT，N_EMBD=32）不变，可以改的只有下游任务、读出方式和预训练预算。

## 通用设置

- 种子 53、71、89、107、131，四档 200、800、3,200、12,800，另加不预训练的 0 档。
- 32 个标签按 numpy default_rng(种子) 在训练池中无放回抽取，和 V1 相同。
- 三种读出：
  - probe：冻结主干，最后一层均值池化表示按 32 个样本标准化，岭回归 alpha=1（V1 的统一口径）。
  - probe-cv：同上，但岭回归的正则强度只用这 32 个标签做留一交叉验证选定，候选 alpha 为 10^-2 到 10^4 的 13 个对数等距值（sklearn RidgeCV 默认的高效留一）。
  - ft：全参数微调 200 步，学习率 0.001（V1 的做法）。

## 判据（开发集和留出组相同）

1. 五种子平均误差在 200 → 800 → 3,200 → 12,800 三段都下降。
2. 12,800 档相对 200 档，至少 4/5 个种子改善。
3. 12,800 档的平均误差不超过只猜均值的 0.7 倍。晶体例外，改为：200、800、3,200、12,800 每一档都低于只猜均值。
4. 12,800 档的平均误差低于不预训练（0 档）。
5. DNA 另要求：所用预训练预算下，预训练留出损失五种子平均三段都下降。

## 各方向候选

**RNA**（Rfam RF01960、RF02543 种子比对的 32 nt 片段，沿用 V1 的固定 1,600 步检查点）。标签都由片段所在列在整个种子比对里的统计得到，不能只从片段本身数出来：
- 保守程度：片段覆盖的 32 个比对列，每列在该家族全部种子序列中非空位碱基的香农熵 H（bit），列保守度 = 1 − H/2，取平均。
- 空位占比：同样 32 列，每列在该家族种子序列中为空位（"-" 或 "."）的比例，取平均。空位多的列对应不同物种间长度可变的区域。

**文本**（Tiny Shakespeare，沿用 V1 的固定 1,600 步检查点）。下游输入改为保留空格的原文，和预训练格式一致：
- 用词常见度：每个词在现代英语里的 Zipf 词频（wordfreq 3.1，'en'），取全行平均。
- 罕见词占比：Zipf 词频低于 3（每百万词出现不到 1 次）的词所占比例。
- 音节数：按 CMU 发音词典（pronouncing 0.3，取第一种读音）数全行音节。行内有词典外的词就把这一行从该任务里去掉。

**晶体**（形成能 e_form，任务不变）：固定 1,600 步检查点和每对象 32 遍检查点，各配三种读出，共 6 种组合。

**DNA**（发夹熔解温度，任务不变）：另训两套共享检查点，固定 3,200 步和固定 6,400 步，其余设置与 V1 的固定 1,600 步相同（同一批酵母基因组窗口、同一顺序）。每套配 ft 和 probe-cv 两种读出。V1 已有的固定 1,600 步、每对象 32 遍两套只作参照，不参与选择。

## 选择与确认

- 只在开发集上选。满足判据的组合中，读出方式优先 probe，其次 probe-cv，再次 ft；同一读出方式取 12,800 相对 200 端点降幅最大者。
- 选中的组合在留出组 A、B 上各评一次。两组都满足判据才算通过，替换 V1 主表的对应行。
- 开发集上没有满足判据的组合，或留出确认未通过，就照实记下，V1 对应行保持不变。

## 补充一：第二批候选（在第一批 RNA、文本、晶体开发结果之后、第二批运行之前写定）

第一批 RNA、文本、晶体在开发集上都没有满足判据的组合（DNA 还在训练，不受影响）。RNA 的两个比对统计任务和文本的三个词汇任务，12,800 档误差都在只猜均值的 0.9 到 1.4 倍。晶体的问题出在读出：不预训练时全参数微调就比只猜均值差，200、800 档跟着差。第二批每个方向再列一组，判据和选择规则不变，选中的组合同样只在 A、B 上评一次。

- **RNA**（固定 1,600 步检查点，probe、probe-cv、ft 三种读出）：
  - 亚基来源：片段来自真核核糖体小亚基 RNA（Rfam RF01960）记 0，大亚基 RNA（RF02543）记 1，按平均绝对误差评。标签来自 Rfam 的家族注释。
  - 相对位置：片段起点在去空位后整条序列中的位置除以序列长度，0 到 1。
- **文本**（固定 1,600 步检查点，probe、probe-cv 两种读出）：V1 已列过的两个任务，换成冻结读出。
  - 被替换字母数：V1 第一批的扰动行任务，输入和标签沿用当时的文件。
  - 去空格后的词数：V1 主表任务。
- **晶体**（形成能，固定 1,600 步和每对象 32 遍两套检查点）：两种更保守的全参数微调。
  - ft-slow：学习率 0.0003，200 步。
  - ft-short：学习率 0.001，100 步。

## 补充二：第三批，读出模型自己的预测损失（第二批开发结果之后、第三批运行之前写定）

第二批 RNA、文本、晶体在开发集上仍没有合格组合。文本“被替换字母数”的冻结读出（probe-cv）四档逐档下降、5/5 种子改善、末档好于不预训练，只差均值门槛（0.90 倍）。另在开发集上用种子 53 做过一次诊断：预训练模型对每行的平均下一个 token 损失，与用词常见度的 Spearman 相关从不预训练的 −0.09 升到 12,800 档的 −0.63，与罕见词占比从 0.10 升到 0.45；RNA 保守程度的相关始终在 ±0.16 以内。诊断只用了开发集，A、B 没有动过。

第三批加两种读出，主干、编码器和预训练检查点都不变：

- nll：冻结主干，用模型自己的下一个 token 预测头，算每个对象逐位置的交叉熵，取平均值和最大值两个数，按 32 个样本标准化，岭回归 alpha=1。晶体用元素预测头，对象内 5 个原子位置。
- probe-cv+nll：均值池化表示和这两个数拼在一起，按 32 个样本标准化，RidgeCV 选正则（候选同 probe-cv）。

候选：文本的被替换字母数、用词常见度、罕见词占比；RNA 的保守程度；晶体形成能（固定 1,600 步、每对象 32 遍两套）。全部用固定 1,600 步检查点，晶体另加每对象 32 遍。判据和选择规则不变，读出优先级排在 probe、probe-cv、ft 之后：nll，再 probe-cv+nll。
