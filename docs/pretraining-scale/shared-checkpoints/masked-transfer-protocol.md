# 文本扰动与缺晶格晶体的独立复验
开发集和确认组评分前锁定。只复用原固定 1,600 步检查点。0、200、800、3,200、12,800 档，种子 53、71、89、107、131。预训练损失一律在干净且完整的输入上测量。

文本从 Tiny Shakespeare 取 24–62 字符、清洗去重的原句。每行均匀抽取 0 至 0.60 的比例，四舍五入成字母个数，等概率改成另一个字母，空格原位保留。标签是实际替换字母数 / 总字母数。每行扰动由句子哈希锁定。比较冻结均值池化线性头和冻结语言模型对该行有效下一字符的平均负对数概率加一维岭回归，alpha=1。后者直接检验语言模型能否从字符上下文识别模拟转录错误。

晶体用 Matbench 钙钛矿，目标为原矩阵体积绝对值的立方根（Å），监督训练和预测时都把整个晶格矩阵置零，其余只给元素和分数坐标。比较冻结均值池化岭回归与仓库原全参数微调。按有序元素和分数坐标去重，晶格不同也不得在新划分之间复用这组输入。

两项都排除原预训练、标签池、开发及两组留出用过的对象。取新训练池 256、开发 480、确认 A/B 各 480，从训练池按原五种子各取 32 个标签。各用途从同一固定排列按序划分。文本按清洗后的唯一行，晶体按遮晶格后的输入排重。确认集只给开发筛出的一个读出评分；额外记录常数和 32 标签随机森林（128 树，种子同标签种子），森林仅作参照。

开发和确认用同一判据：平均下游 MAE 四档严格三段下降，末档相对首档至少 4/5 种子改善，末档误差低于零预训练并且不超过只猜均值的 0.70 倍；平均预训练损失四档三段下降。多个读出都通过时选末档 MAE 最小者。任一确认组未达标则保留旧默认，不再换读出或改阈值。
