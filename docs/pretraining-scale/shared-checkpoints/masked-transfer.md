# 换下游后，预训练收益还在吗？

文本换成估计字母扰动率，晶体在监督阶段遮住晶格矩阵。两项都沿用原来的编码器、两层 nanoGPT 和每档固定 1,600 步的预训练权重。五个种子各抽 32 个标签训练读出。表中是五种子平均绝对误差，越低越好。0 档用随机初始化的主干。预训练在完整、干净的观测上评估，读出只看任务允许的输入。

**文本。** 在 Tiny Shakespeare 的真实英文行中随机替换最多约六成字母，保留空格，预测实际替换比例。监督标签由模拟生成。冻结模型先给每个真实出现的字符打分，再把非填充位置的平均负对数概率用一维岭回归映射为扰动率。该读出在 3,200 档的平均误差约为 5.84 个百分点，猜均值约为 15.17 个百分点。干净文本的下一字符损失从 1.8220 继续降到 1.8004，下游误差在这一步略升，开发筛选到此结束。两组确认数据未评分。

**晶体。** 标签从 Matbench 钙钛矿的计算晶胞取体积立方根。预训练时有晶格 token，监督训练和预测时把它的九个数全部置零。一个新对象只提供原子种类和分数坐标。在两组确认样本上，冻结读出的末档误差分别比只猜均值低 31.5% 和 31.0%，比同输入的随机森林低 30.8% 和 27.9%。预训练损失在两组都三段下降。下游误差在 200 → 800 档分别增加 0.0099 Å 和 0.0030 Å。这个对照支持从更大量无标签晶胞中学到有用表示；四档严格逐级下降的条件没有满足。

每项另取 256 个对象作为标签池、480 个作开发集、两组各 480 个作确认集。新对象与原无标签、监督和评估对象按清洗去重的文本行或遮住晶格后的有序元素与分数坐标排重。划分不检验跨作者或跨晶体家族的泛化。两项默认演示均沿用此前版本；原晶体默认任务含晶格矩阵，课堂上应明确它用于演示读数精度。
