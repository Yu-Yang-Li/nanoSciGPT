# 同一方向共享预训练权重，更换下游任务

每个方向只用一套预训练权重：上一轮“固定 1,600 步”实验里已经封存的 220 个检查点（11 个方向 × 5 个种子 × 200、800、3,200、12,800 四档）。所有下游任务都从这同一批权重开始微调，另加不预训练的 0 档作参照。

微调统一为：同一个均值池化加线性标量头，32 个标签，全参数更新 200 步，学习率 0.001，种子 53、71、89、107、131。32 个标签的行号为 numpy default_rng(种子) 在训练池中无放回抽 32 个，连续块的标准化沿用该检查点训练时的同一组统计量。每个任务在两组留出样本上各报一次平均绝对误差。

下游任务在运行前全部列定，全部报告，不做挑选：

- 光谱：紫外 250 nm 与 700 nm 通量比（对数）
- 蛋白质：色谱保留时间（实测）
- DNA：三核苷酸熵、二阶碱基条件熵、最长同碱基段（基因组窗口）；发夹熔解温度（实测，另一组序列，同一词表）
- RNA：三核苷酸熵、共识配对状态切换次数
- 小分子：环内重原子比例、重原子图直径、sp³ 杂化碳比例、转动常数 B（QM9）
- 晶体：形成能
- 三维结构：首尾距、回转半径（输入遮去含首尾距的两个距离块）
- 天气场：云团移动速率
- 扩散场：扩散系数对数
- 天文图像：星像半高全宽、星数
- 文本：被替换字母数（扰动行）、去空格后的词数

判据与此前一致：两组留出的五种子平均误差在 200 → 800 → 3,200 → 12,800 三段都下降，记为“逐档改善”；另报 12,800 相对 200 的端点降幅和改善种子数。小分子 logP 的分子含 Cl、Br、S 等 QM9 词表外的符号，无法用这套权重编码，未列入。

## 补充约定（开发集结果出来前写定）

共享检查点上的全参数微调，在两组留出数据上只有 4 个方向出现逐档下降的下游任务。另试一种读出：主干冻结，对最后一层的均值池化表示按 32 个训练样本做标准化，再用岭回归（alpha=1）读出一个标量。两种读出都只在各方向原有的开发样本上评估。

选择规则：
1. 统一读出方式：在开发集上，哪种方式让更多方向至少有一个任务满足“五种子均值四档逐档下降，且 12,800 档相对 200 档至少 4/5 个种子改善”，就用哪种；平局时沿用全参数微调。
2. 每个方向在满足条件的任务中，取开发集端点降幅最大的一个。
3. 选定后在留出组上只评一次。如果选中的读出方式此前已在 A、B 上评过，就为相应方向另外生成两组新的留出样本。
## 第二批候选（开发结果出来前写定）

光谱、天气场、扩散场、晶体四个方向在第一批任务中没有合格项，再补以下候选。模拟方向按原随机流重新生成，核对输入与面板逐项一致后取出生成参数；晶体从晶胞元素计算。

- 光谱：冷成分温度、热成分温度（千开）、热成分占比
- 天气场：东西向速度分量、两个云团的平均宽度、平均亮度
- 扩散场：初始场能量（对数）、基模能量占比
- 晶体：A、B 两个阳离子的平均 Pauling 电负性，三个阴离子位点平均值与阳离子平均值之差

读出方式沿用开发集已选定的冻结主干加岭回归，选择规则不变；选中的任务在 A、B 上只评一次。
## 第三批：光谱、扩散场、晶体改用固定遍数的共享检查点（运行前写定）

这三个方向在固定 1,600 步的检查点上没有任何下游任务合格。扩散场的预训练损失本身在 12,800 档回升。改为每个对象平均训练 32 次（步数为对象数的一半，即 100、400、1,600、6,400 步），其余设置不变，每个方向重新训练一套 20 个共享检查点。先报两组留出的预训练损失，再按同样规则在开发集上从该方向全部候选任务、两种读出方式中选择，选中的组合在 A、B 上只评一次。这些检查点是新训练的，A、B 上的分数此前未出现过；但改用这套预算是在看到第一套检查点的留出结果之后决定的。
## 第四批：DNA 改用固定遍数的共享检查点（运行前写定）

DNA 的下游任务在固定 1,600 步检查点上已经确认，但预训练损失最后一段持平（3,200 → 12,800 相差约 10⁻⁵），未达到逐档下降。按第三批的同一方案（步数为对象数的一半）重训 20 个 DNA 检查点，先报留出预训练损失；再从 DNA 的四个候选任务和两种读出中按同一规则在开发集上选择，A、B 只评一次。两套 DNA 结果都保留。
