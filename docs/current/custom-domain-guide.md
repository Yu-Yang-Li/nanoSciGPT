# 把自己的科学数据接入 nanoSciGPT

课堂仓库内置十类可离线运行的样例，用来说明同一训练骨架怎样处理不同科学对象。它们并不承诺任意新数据放进目录就能自动训练。接入自己的数据时，需要先把下面五件事说清并实现，再加入 `nanoscigpt/domains/registry.py`。

## 已经可以直接接入的格式

| 学生数据 | 当前入口 | 当前边界 |
|---|---|---|
| 带标签表格CSV | `nanoscigpt-baseline --csv` | 分类或回归；需要明确目标列 |
| 单条数值时序CSV | `nanoscigpt-baseline --series-csv` | 单变量预测；指定时间列或明确沿用行顺序 |
| 蛋白质FASTA | `nanoscigpt.domains.protein.prepare --fasta` | 可在自有序列上预训练；无功能标签时运行课程命令需加`--skip-downstream` |
| DNA FASTA | `nanoscigpt.domains.dna.prepare --fasta` | 可在自有序列上预训练；无目标标签时可加`--skip-downstream` |

天气网格、晶体、三维结构、图像、光谱和连续物理场目前仍只提供内置教学夹具。学生自己的这些数据需按下列五个接口接入，不能直接套用内置样例的结果。

## 五个必需接口

| 接口 | 需要回答的问题 | 最小产物 |
|---|---|---|
| 数据读取 | 一个样本是什么，缺失值和异常值怎样处理？ | 能稳定返回训练与验证样本的读取函数 |
| 科学表示 | 模型每次看到的是字符、片段、邻域、网格块还是连续区间？哪些关系不能在转换中丢失？ | 张量或 token 序列，以及表示说明 |
| 预训练目标 | 在不使用下游标签时，模型根据什么误差更新？ | 能在训练样本上计算的损失函数 |
| 下游任务 | 预训练结果最终用于分类、回归、生成还是模拟？ | 少量带标签样本和任务头或探针 |
| 评价器 | 什么数值决定继续、停止或退回基线？ | 固定指标、方向和最低变化门槛 |

## 接入顺序

1. 复制 `examples/custom_domain/`，先写一页数据说明，不先改训练器。
2. 用十到几十条样本跑通数据读取和科学表示，保存一个可目视检查的样例。
3. 让预训练目标在极小数据上出现可解释的损失变化。
4. 接入一个足够简单的下游任务，确认预训练表示确实被读取。
5. 给评价器写测试，再把该领域注册为 `DomainSpec`。

如果科学对象需要新的图网络、等变网络、物理求解器或实验接口，应新增相应的专用模块；不要为了复用 GPT 外壳而把关键几何或物理关系压扁成无意义的字符串。
