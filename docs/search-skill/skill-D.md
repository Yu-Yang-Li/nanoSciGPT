一、按输入类型与起点读出方式的前几轮优先级。1) 符号序列（蛋白质/DNA/RNA/小分子）：若起点是 probe，第1轮先试 readout=finetune（蛋白质2/2、小分子2/2 改善；RNA 2/2 变差，故仅作首选试探，若首轮无改善立即转向）。若起点已是 finetune，第1轮先试 objective=masked, mask_ratio=0.3（DNA 2/2 改善，约0.80–0.83）。2) 数值块序列（光谱/天气/扩散/天文）：起点为 probe 时，优先试 masked+较高 pretrain_lr（0.003）或 ridge_alpha=10（天气 2/2 改善，约0.82–0.85；光谱 masked 2/2 变差，故需首轮验证）。起点为 finetune 时，优先试 merge=2 配合 finetune_steps=400/finetune_lr=0.0003（扩散 2/2 改善，约0.76；光谱 finetune 2/2 改善约0.79）。3) 晶胞：起点为 finetune 时，唯一稳定的是 finetune_steps=400（2/2，约0.995，幅度极小）；其余改动普遍无效或有害，应保守。二、通常无用或有害的改动。merge=2 在符号序列上多数有害（蛋白质 3/3 变差、DNA 随机搜索多次变差、RNA 多次变差；仅小分子个别组合有效），除数值块序列外不要默认开启。pool=last 普遍有害（蛋白质、DNA、RNA、天气、天文多次变差；仅 RNA probe 下略好），除起点 probe 且 ridge_alpha=10 的个别情形外不优先。objective=skip 在多数方向无改善或有害（蛋白质、DNA、RNA、天气、天文随机搜索多为>1），不优先。pretrain_steps 缩短到 1/4 或 1/2 多数有害（蛋白质、DNA、RNA、天气、天文随机搜索多次>1），仅在数值块序列配合 merge+masked 时偶有改善（扩散 2/2 约0.84–0.88），不通用。pretrain_lr=0.003 在符号序列上常有害（DNA、RNA、蛋白质多次>1），仅在数值块序列 probe 起点下可试（天气 2/2 改善）。三、8 轮分配建议。第1轮：按上述类型/读出方式的首选单改动。第2轮：若第1轮改善，叠加同族第二改动（如 finetune 后加 finetune_lr=0.0003 或 finetune_steps=400；masked 后调 mask_ratio 0.5）；若无改善，换到另一主族（readout 与 objective 互换）。第3–4轮：在已验证有效的族内做小步调参（mask_ratio、ridge_alpha、finetune_steps），每次只改一项。第5–6轮：尝试组合两个已验证有效的改动，但避免 merge+last 同时开启。第7–8轮：保留一次对起点附近稳健配置的复测（如 finetune_steps=400 或 ridge_alpha=10），用于确认是否应停在起点。四、何时停在起点。若前4轮所有改动开发集误差均≥0.98 且种子区间跨1，尤其晶胞类（多次约0.99–1.0）或 RNA（多次约0.97–1.0），应停止并选起点；留出评估显示起点最稳（晶胞、RNA 随机搜索多次留出≈1.0）。若最佳开发集改善<5% 且种子区间宽（跨1），也倾向停在起点。
